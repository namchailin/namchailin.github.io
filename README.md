# namchailin.github.io

My personal homepage — <https://namchailin.github.io>

I'm a master's student in the School of Software at Soongsil University and a member of the
Natural Language Processing Lab. My work is on natural language processing and large language
models, mostly around building autonomous agents that understand and interact with people.

The site collects my education, publications, patents, and contact details in one place.
My CV lives here too, as `chailin_CV.pdf`.

Built with Jekyll and hosted on GitHub Pages. The layout started from Ankit Sultana's
[researcher](https://github.com/ankitsultana/researcher) theme.
